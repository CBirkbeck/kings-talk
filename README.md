# Kings talk — Maths in the age of AI

Slides by Chris Birkbeck, University of East Anglia.

[View the slides](https://cbirkbeck.github.io/kings-talk/)

Use the arrow keys to navigate; press **F** for fullscreen or **Esc** for an overview.

## Editing and previewing

Edit `index.html`. The presentation uses the bundled reveal.js files and needs no build step.

Run `python3 -m http.server 8000` from this directory and open http://localhost:8000.

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the site.

The linked example PDFs are included. Some slides link to external services that may require sign-in.

The bundled reveal.js framework is MIT licensed; see `LICENSE`.
